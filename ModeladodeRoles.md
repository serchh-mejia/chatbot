# Modelado de Roles

| Rol                    | Función Principal                      | Permisos                                                                                                                                   |
| ---------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Administrador          | Control total del sistema              | Crear, editar y eliminar usuarios; configurar el chatbot; administrar productos y pedidos; generar reportes; acceder a toda la información |
| Usuario / Cliente      | Interactuar con el chatbot             | Realizar consultas, hacer pedidos, visualizar información y estado de solicitudes                                                          |
| Auditor                | Supervisar y verificar procesos        | Consultar historial, revisar reportes y monitorear actividades sin modificar datos                                                         |
| Soporte Técnico        | Mantener el funcionamiento del sistema | Resolver errores técnicos, actualizar configuraciones y monitorear el rendimiento                                                          |
| Supervisor de Atención | Controlar la calidad del servicio      | Revisar conversaciones, evaluar respuestas y supervisar la atención al cliente                                                             |
| Operador de Inventario | Gestionar productos y disponibilidad   | Actualizar stock, registrar productos y verificar disponibilidad                                                                           |
| Gerente                | Tomar decisiones estratégicas          | Visualizar estadísticas, analizar reportes y aprobar mejoras del sistema                                                                   |
| Chatbot Inteligente    | Automatizar la atención al cliente     | Responder preguntas frecuentes, registrar consultas y brindar asistencia automática 24/7                                                   |

## Descripción General

El sistema BOXCHETT maneja diferentes roles para garantizar una correcta administración, control y funcionamiento de la plataforma. Cada usuario posee permisos específicos según sus responsabilidades dentro del sistema.

Los administradores tienen acceso completo al sistema, mientras que los usuarios interactúan directamente con el chatbot para resolver consultas y realizar solicitudes. Los supervisores y auditores controlan la calidad y transparencia del servicio, y el soporte técnico garantiza la estabilidad y seguridad del sistema.
